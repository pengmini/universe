# 소통의 우주 (Communication Universe)

학생들의 학급 내 상호작용을 3D 우주로 시각화하는 교육용 웹앱.
학생이 크롬북에서 글을 올리면 교실 전자칠판의 우주에 **실시간으로** 위성이 생깁니다.

**Phase 1 — Firebase 연동 + 구글 로그인 완료.**

```
index.html      로그인 게이트 → 역할에 따라 자동 이동
teacher.html    교사 · 전자칠판 (3D 우주 + 읽기 전용 피드)
student.html    학생 응답 페이지 (전통놀이 · 음악 취향)
app/config.js   ★ Firebase config — 여기만 채우면 됩니다
app/auth.js     로그인 · 로그아웃 · 권한 판정 · 페이지 가드
app/data.js     Firestore 읽기 · 쓰기
app/demo.js     시연용 예시 데이터 (Firestore 에 쓰지 않음)
app/ui.css      공통 스타일
firestore.rules 보안 규칙 (반드시 배포)
```

빌드 도구가 없습니다. ES 모듈을 브라우저가 직접 읽습니다.

## 설치 — 다섯 단계

### 1. Firebase 콘솔 설정

1. **Firestore Database** 만들기 — 위치는 `asia-northeast3 (서울)` 권장
2. **Authentication → Sign-in method → Google** 사용 설정
3. **Authentication → Settings → 승인된 도메인**에 배포 주소 추가
   - `localhost` (기본 포함)
   - `<계정>.github.io` 또는 `<프로젝트>.vercel.app`

> 이 단계를 빠뜨리면 로그인 시 `auth/unauthorized-domain` 오류가 납니다.
> 로그인 화면이 이 오류를 한글로 안내하도록 해 뒀습니다.

### 2. `app/config.js` 채우기

Firebase 콘솔 → 프로젝트 설정(⚙) → 내 앱 → **SDK 설정 및 구성 → 구성** 의 객체를 붙여넣습니다.

```js
export const firebaseConfig = {
  apiKey: "AIza…", authDomain: "…firebaseapp.com", projectId: "…",
  storageBucket: "…appspot.com", messagingSenderId: "…", appId: "…",
};
```

> 웹 API 키는 **비밀이 아닙니다.** 브라우저에 공개되는 것이 정상이고,
> 실제 접근 통제는 다음 단계의 보안 규칙이 합니다.

### 3. 보안 규칙 배포 — 건너뛰지 마세요

콘솔 → Firestore → **규칙** 탭에 `firestore.rules` 내용을 붙여넣고 게시합니다.
또는 CLI로:

```bash
npm i -g firebase-tools
firebase login
firebase deploy --only firestore:rules
```

`firestore.rules` 안의 교사 이메일과 `app/config.js` 의 `TEACHER_EMAIL` 을
**항상 같게** 유지하세요.

### 4. 로컬에서 확인

```bash
python3 -m http.server 8000     # → http://localhost:8000
```

`file://` 로 직접 열면 **안 됩니다.** ES 모듈은 `http(s)` 로만 로드됩니다.

### 5. 배포

**Vercel** — `npx vercel`. 프레임워크 **Other**, 빌드 설정 없음.
**GitHub Pages** — Settings → Pages → Source `main` / `(root)`.
파일들이 **저장소 루트**에 있어야 합니다.

배포 후 1번의 승인된 도메인에 실제 주소를 꼭 추가하세요.

## 예시 데이터로 시연하기

Firestore 가 비어 있으면 교사 화면이 텅 빕니다. 고장인지 빈 것인지 헷갈리죠.
교사 화면 하단 **[예시 데이터]** 버튼을 누르면 세 주제의 예시가 얹힙니다 —
**단소 행성도 여기서 위성과 별을 갖고 시연됩니다.**

지켜지는 규칙이 있습니다.

- **Firestore 에 쓰지 않습니다.** 메모리에만 얹히고, 버튼을 끄면 사라집니다.
- **실제 글이 하나라도 있는 주제에는 붙지 않습니다.** 진짜와 섞이지 않습니다.
- **집계에서 빠집니다.** 하단 통계, 「참여 적은 친구」 명단, 숨은 태양 후보 모두
  예시 학생을 제외합니다. 수업 중에 켜도 가짜 아이가 태양으로 뽑히지 않습니다.
- 화면 위에 **"예시 데이터 표시 중"** 배너가, 카드에는 **예시** 꼬리표가 붙습니다.

예시가 더 필요 없으면 `app/demo.js` 와 `teacher.html` 의 import 한 줄만 지우면 됩니다.

## 동작 확인 체크리스트

배포한 뒤 순서대로 눌러 보세요. 저는 Firebase 프로젝트가 없어 여기까지는 확인하지 못했습니다.

| # | 확인할 것 | 기대 결과 |
|---|---|---|
| 1 | 아무 계정도 없는 상태로 `teacher.html` 직접 접속 | `index.html` 로 튕겨 나감 |
| 2 | 로그인 화면에서 **교사 계정**으로 로그인 | `teacher.html` 로 이동, 헤더에 이름 + `교사` 배지 |
| 3 | 로그인 화면에서 **다른 구글 계정**으로 로그인 | `student.html` 로 이동, 배지는 `학생` |
| 4 | 학생 계정으로 `teacher.html` 주소 직접 입력 | `student.html` 로 되돌려 보냄 |
| 5 | 학생이 글 올리기 | 교사 화면 3D 우주에 위성이 **새로고침 없이** 생김 |
| 6 | 같은 학생이 같은 주제에 또 올리기 시도 | 입력창 대신 "내 글을 올렸어요" 표시 |
| 7 | 다른 학생이 공감 | 위성 주위에 숨은 별 추가 |
| 8 | 같은 학생이 같은 글에 공감 두 번 | 버튼이 "공감함" 으로 비활성 |
| 9 | 자기 글에 공감·댓글 | 버튼 비활성 |
| 10 | 댓글 쓰기 | 위성을 도는 작은 구가 생기고, 호버 시 내용 표시 |
| 11 | 로그아웃 | 로그인 화면으로 돌아감 |
| 12 | 탭을 닫았다 다시 열기 | 로그인 상태 유지 (`browserLocalPersistence`) |
| 13 | 교사 화면에서 **[예시 데이터]** 켜기 | 세 주제에 예시 위성, 단소 행성에도 위성이 생김 |
| 14 | 예시를 켠 채 하단 통계 확인 | 숫자는 **실제 데이터만** 셈 (예시 제외) |
| 15 | 예시를 켠 채 **숨은 태양 띄우기** | 예시 학생은 후보에 없음 |

**규칙이 실제로 막는지도 확인하세요.** 콘솔 → Firestore → 규칙 → **Playground** 에서
학생 uid 로 `satellites/t1__다른사람uid` 생성을 시도하면 거부되어야 합니다.

## 권한 구조

| | 교사 (`pengmini90@gmail.com`) | 학생 (그 외 모든 구글 계정) |
|---|---|---|
| 로그인 후 이동 | `teacher.html` | `student.html` |
| 글 읽기 | ○ | ○ |
| 글 올리기 | × (교사 화면은 읽기 전용) | ○ 주제당 1개 |
| 공감 · 댓글 | × | ○ 글당 각 1회, 자기 글 제외 |
| 삭제 | ○ | × |
| 3D 우주 · 숨은 태양 | ○ | × |

> **클라이언트의 `TEACHER_EMAIL` 은 보안 장치가 아닙니다.** 브라우저에서 누구나 고칠 수
> 있으므로 화면 이동에만 씁니다. 실제 권한은 `firestore.rules` 의 `isTeacher()` 가 막습니다.

### 중복 방지

Firestore 에는 UNIQUE 제약이 없습니다. **문서 ID를 결정론적으로** 잡고, 그 ID가 본인
uid 로 만들어졌는지 규칙에서 검사합니다. `create` 는 문서가 이미 있으면 실패합니다.

```
satellites/{topicId}__{uid}             한 주제에 한 사람 한 글
interactions/{satId}__{uid}__{type}     한 글에 공감 1 · 댓글 1
```

## 데이터 구조

```
satellites/{topicId}__{uid}
  topicId, uid, studentName, content, createdAt

interactions/{satId}__{uid}__{type}
  satId, topicId, fromUid, fromName, type("like"|"comment"), text, createdAt
```

**집계(공감 수 등)는 저장하지 않습니다.** 클라이언트가 `interactions` 를 세어 씁니다.
학급 규모(수백 건)에서는 충분하고, 카운터 불일치 버그가 원천적으로 없습니다.
학년 전체로 키울 때 Cloud Functions 트리거로 옮기세요.

주제 정의(`TOPICS`)는 사용자 데이터가 아니라 설정값이라 `app/config.js` 에 둡니다.
`active:false` 인 주제는 학생 화면에 나오지 않습니다. **단소(`t3`)가 지금 그 상태**입니다 —
데이터 구조와 3D 행성은 남아 있고 학생용 UI만 없습니다.

## 알려진 한계 — 다음 단계에서 처리

- **학급 명단이 없습니다.** 지금은 데이터에 등장한 이름만 학생으로 봅니다.
  그래서 **한 번도 로그인하지 않은 학생은 「참여 적은 친구」에 잡히지 않습니다.**
  이 기능을 제대로 쓰려면 교사가 명단(이메일↔이름)을 등록하는 화면이 필요합니다.
- **구글 계정이면 누구나 학생으로 들어옵니다.** URL을 아는 외부인도 글을 올릴 수 있습니다.
  학교 도메인 제한이나 교사 승인제가 필요하면 규칙에 한 줄 추가하면 됩니다.
- **이름은 구글 계정 이름을 그대로 씁니다.** 실명이 아닌 계정이 섞일 수 있습니다.
- **단소 주제** 학생 입력 UI 미구현 (3D·구조·예시 데이터는 있음).
- 부적절한 입력 필터링 없음.
- 세션 종료 후 데이터 삭제 정책 없음.
- **「참여 적은 친구」를 교실 전체 화면에 띄울지** 결정 필요 — 낙인 위험이 있어
  교사 개인 화면에서만 보이게 하는 쪽을 권합니다. 현재는 토글로 끌 수 있게만 해 뒀습니다.

## 개발 노트 — 코드에 손대기 전에

### `>>` 대신 `>>>`

궤도 속도·반지름을 해시 비트에서 뽑을 때 **부호 있는 시프트를 쓰면 안 됩니다.**
32비트 값의 최상위 비트가 켜져 있으면 음수가 나오고, JS는 `음수 % n` 도 음수입니다.

```js
const h = 2445500455;
h >>  22   // -441  ← spd 가 0 근처로 상쇄되어 '공전하지 않는' 천체가 생긴다
h >>> 22   //  583
```

실제로 이 버그로 댓글 17개 중 10개, 위성 22개 중 6개가 멈춰 있었습니다.
지금은 `bits(h, shift, mod)` 헬퍼로 통일했습니다.

### 궤도 상태는 3D 오브젝트가 아니라 데이터에

Firestore 스냅샷이 올 때마다 `buildSats()` 가 3D를 통째로 다시 만듭니다.
궤도 각도를 메시에 두면 모든 천체가 초기 각도로 **한꺼번에 순간이동**합니다.

### 해시에 고유값을 충분히 섞기

`sa.id.length` 처럼 일부만 쓰면 서로 다른 위성이 같은 해시를 냅니다.
`hashStr(sa.id + "#" + k)` 로 id 전체를 섞으세요.

### 궤도 반지름은 부모 크기에 비례시키기

고정값이면 부모가 커졌을 때 자식이 **속에 파묻힙니다.**
위성은 `행성 반지름 × 1.62 + 여유분`, 댓글 구는 `위성 반지름 × (1.95~3.05)` 를 씁니다.

## 시각 규칙

| 요소 | 정체 | 크기 · 동작 |
|---|---|---|
| **주제 행성** | 대주제 | 위성이 늘수록 커지고 발광 증가 |
| **위성 행성** | 학생이 올린 글 | 상호작용이 많을수록 크고 밝고 공전이 빨라짐 |
| **숨은 별** | 공감 | 위성 지름의 1/2. 평소 투명도 16%, 호버 시 92%. 공전하지 않음 |
| **댓글 구** | 댓글 (내용 포함) | 위성 지름의 1/3. 위성을 6~15초 주기로 공전 |
| **숨은 태양** | 마무리 연출 | 우주 전체에서 3명 무작위(중복 없음) 또는 교사 지정 |
| **분홍 별** | 참여가 적은 학생 | 토글로 끄면 3D 씬에서 완전히 사라짐 |

## 기술

- **3D** Three.js r128 (CDN, UMD) — 텍스처는 전부 `<canvas>` 런타임 생성
- **백엔드** Firebase v10.12.2 (Auth + Firestore), ESM CDN 직접 import
- **폰트** Google Fonts — Jua, IBM Plex Sans KR, IBM Plex Mono

Firebase SDK 버전을 올리려면 `app/auth.js` 와 `app/data.js` 의 import URL
세 줄만 바꾸면 됩니다.
